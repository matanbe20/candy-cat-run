# חתולת הממתקים · Candy Cat Run

A 3D toon / comic-book endless runner in the browser. A white British Shorthair with a purple bow runs down a cozy cartoon street toward candy mountains, collecting sweets and dodging grumpy street cats.

**Play:** https://matanbe20.github.io/candy-cat-run/

- `index.html`: the game (single self-contained file, Three.js from a CDN)
- `style-preview.html`: the approved style showcase (orbit camera, animation preview, style controls)

Everything is generated in code: models from Three.js primitives, textures on canvas, and sound with the Web Audio API.

## Controls

| | Keyboard | Mobile |
|---|---|---|
| Change lane | ← → / A D | swipe left / right |
| Jump | ↑ / W / Space | swipe up |
| Duck / slide (in the air: fast drop) | ↓ / S | swipe down |
| Pause / mute | P or Esc / M | on-screen buttons |
